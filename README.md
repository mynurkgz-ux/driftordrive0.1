# Drive or Drift

2D-игра про дрифт и гонки с видом сверху. Работает в браузере на компьютере и телефоне, без сборки — обычные HTML/CSS/JS.

## Что внутри

- **3D-графика (three.js):** реалистичные модели машин — кузов с арками, стёкла, диски с суппортами, фары со светом, отражения краски, тени. Сцены в меню: дрифт с облаком дыма и гонка по снегу. В гараже машина стоит на поворотном столе, а в самой игре используется вид этой же 3D-модели сверху. Если three.js не загрузится (нет интернета или сайт открыт как файл), игра автоматически переключится на 2D-графику.
- **Главное меню:** текущая машина на подиуме и её характеристики слева, кнопки Дрифт · Гонка · Гараж справа, настройки — шестерёнка в правом верхнем углу.
- **Дрифт:** анимация машины в заносе с дымом. 32 карты: кольца, серпантины, площадки с конусами. Очки за угол и скорость, множитель комбо до x5, комбо сгорает при ударе или вылете. Сессия длится 2:30, за цель открывается следующая карта.
- **Гонка:** вид сбоку с анимацией скорости. 32 трассы (кольца и овалы), 3–4 круга против 5 соперников под управлением ИИ. За 1–3 место открывается следующая трасса.
- **Гараж** (нажми на машину на экране режима):
  - **Машины:** 75 моделей, 12 типов кузова, классы D…S+.
  - **Обвесы:** 60 вариантов на каждую машину — фары, капот, спойлеры, бамперы, пороги, расширители, крыша, зеркала. Часть обвесов влияет на прижим и сцепление.
  - **Цвет:** кузов (глянец, металлик, мат, перламутр, хром), диски, фары, неон.
  - **Винил:** 23 узора и 2 цвета.
  - **Тюнинг:** двигатель, турбина, шины, облегчение, тормоза. Настройки подвески: угол руля, жёсткость, развал, клиренс, дифференциал, баланс тормозов.
- **Физика:** реалистичный разгон и торможение, перенос веса, круг трения шин (пробуксовка срывает зад в занос), ручник. Машины отличаются управляемостью: привод, масса, развесовка.
- **Сохранение:** у гостя всё хранится в браузере, после регистрации — в облаке Firebase. Сохраняются машины, обвесы, деньги, открытые карты и настройки.
- **Аккаунт:** регистрация (ник, email, пароль), вход, смена ника и пароля, сброс пароля по email. После входа ник `Игрок###` заменяется на настоящий.
- **Мультиплеер:** выбираешь карту, игра создаёт комнату и ссылку. Друг открывает ссылку (или вводит код) и попадает в ту же комнату.
- **Настройки:**
  - На ПК: музыка (6 сгенерированных треков + своя музыка из файла), звук (мотор, шины, окружение, эффекты), ссылка на сайт, аккаунт.
  - На телефоне дополнительно: управление (джойстик / кнопки / руль), редактор расположения кнопок, ориентация экрана.

Управление на ПК: **WASD / стрелки**, **Пробел** — ручник, **R** — вернуться на трассу, **C** — камера, **Esc** — пауза. Геймпад тоже поддерживается.

## Запуск на компьютере

Дважды кликни **`start.bat`**: он поднимет локальный сервер на `http://localhost:8080` (нужен Python или Node.js).
Можно открыть и `index.html` напрямую, но тогда не будут работать аккаунты и мультиплеер.

## Настройка Firebase (один раз)

В [консоли Firebase](https://console.firebase.google.com/) для проекта `thedrive01`:

1. **Authentication → Sign-in method** → включи **Email/Password**.
2. **Firestore Database → Create database** (любой регион). Без этого не работают облачные сохранения и мультиплеер.
3. **Firestore Database → Rules** → вставь содержимое файла `firestore.rules` → **Publish**.
4. **Authentication → Settings → Authorized domains** — `localhost` и `*.web.app` уже есть. Если будешь размещать сайт на другом домене, добавь его сюда.

### Мультиплеер плавнее (рекомендуется)

Firestore на бесплатном тарифе даёт ~20 000 записей в день. Мультиплеер пишет позицию 5 раз в секунду, поэтому этого хватит примерно на час игры в день на всех.
Лучше подключить Realtime Database — там нет лимита на число записей, а обновления идут 12 раз в секунду:

1. **Realtime Database → Create database**.
2. **Rules** → вставь содержимое `database.rules.json` → **Publish**.
3. Скопируй адрес базы (например `https://thedrive01-default-rtdb.firebaseio.com`) и раскомментируй строку `databaseURL` в `js/config.js`.

## Публикация сайта (чтобы друзья могли зайти по ссылке)

```
npm install -g firebase-tools
firebase login
firebase use thedrive01
firebase deploy
```

Сайт откроется по адресу `https://thedrive01.web.app`. Ссылки-приглашения в мультиплеер будут вести туда.
Ссылка вида `http://localhost:...` работает только на твоём компьютере.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html`, `css/style.css` | Разметка и стили всех экранов |
| `js/config.js` | Ключи Firebase и ссылка на сайт |
| `js/data.js` | Машины, обвесы, винилы, темы, карты, тюнинг |
| `js/physics.js` | Физика машины и коробка передач |
| `js/track.js` | Генерация трасс, декорации, отрисовка |
| `js/car3d.js` | 3D-модели машин и сцены меню и гаража (three.js) |
| `js/carRender.js` | Отрисовка машин (сверху и сбоку) со всеми обвесами |
| `js/game.js` | Игровой цикл, ИИ, очки дрифта, круги, столкновения, частицы |
| `js/audio.js` | Синтезированная музыка, мотор, шины, звуки окружения |
| `js/controls.js` | Клавиатура, геймпад, сенсорное управление, редактор кнопок |
| `js/net.js` | Аккаунты, облачные сохранения, мультиплеер |
| `js/save.js` | Локальное сохранение прогресса |
| `js/ui.js` | Меню, гараж, выбор карт, лобби, настройки |
